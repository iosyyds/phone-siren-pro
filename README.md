# 手机警报器 Pro 网页版 (Mobile Siren Pro)

基于 Web Audio API 的应急警报器模拟控制台，参考小德车机《手机警报器》界面重构。纯前端单文件实现，无需后端，可直接打开 `index.html` 使用。

## 功能
- 8 大功能模块：号角与广播 / 战术警灯 / 手动电笛 / 巡航警报 / 急促警报 / 特种与轮换 / 双音并发 / 系统控制
- LED 警灯条联动：自动 / 模式1示宽 / 模式2双爆 / 模式3大循环 / 拦停检车前射灯
- Web Audio 实时合成：巡航 Wail / 急促 Yelp / 战术颤音 / 救护 Hi-Lo / 双音并发 / 手动电笛爬升滑落 / 气笛号角 / 重低音脉冲 / 自动随机轮换
- 全局均衡（180Hz / 1000Hz / 4000Hz）+ 混响，参数本地持久化
- 车外广播：实时 / 回放（录音循环）双模式
- 中英文切换、低功率 -12dB、一键全停
- 使用声明（同意进入 / 拒绝锁定）
