# 手机警报器 Pro · 网页版

纯前端实现的警报音效模拟器，复刻「手机警报器 Pro」App 的操作界面。声音全部由 **Web Audio API 实时合成**，无需任何音频文件。

## 功能

- 号角与广播：汽笛号角、广播喊话（麦克风）
- 战术警灯：代码 1/2/3、大循环、导流、探照灯、全屏横屏模式（屏幕光效模拟闪光灯）
- 手动电笛：高音/低音，长按爬升、松开滑落/飞轮拖尾
- 巡航与开道：巡航 Wail、特种开道、工程抢险
- 急促警报：急促 Yelp、追击变频、极速穿透
- 特种与轮换：战术颤音、救护 Hi-Lo、自动随机轮换
- 双音并发：巡航+急促、急促+颤音
- 系统控制：重低音脉冲、闪光灯联动、调音设置（音量/音调/震动）、一键全停

## 使用

直接打开 `index.html` 即可，或部署到任意静态托管。

- 声音由 Web Audio 实时合成，首次点击时浏览器会请求音频播放许可
- 浏览器无法调用手机闪光灯，警灯以屏幕光效模拟
- 广播喊话需要麦克风权限（建议佩戴耳机防回授）
- iPhone 请关闭侧边静音键以获得声音
